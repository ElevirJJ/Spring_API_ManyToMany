# Estudo de Relacionamento Many-to-Many com JPA

Este projeto foi desenvolvido com o objetivo de estudar e praticar o mapeamento de relacionamentos **Many-to-Many** utilizando **JPA** e **Hibernate**.

Durante a implementação, foram aplicados conceitos de **boas práticas de desenvolvimento**, como:

* Organização clara das camadas da aplicação;
* Separação de responsabilidades;
* Código limpo e de fácil manutenção;
* Uso de anotações do JPA de forma adequada;
* Estrutura pensada para facilitar entendimento e evolução.

O projeto serve como uma base simples e objetiva para compreender como funciona a associação muitos-para-muitos em aplicações Java, além de reforçar princípios essenciais de desenvolvimento com foco em qualidade e legibilidade do código.
